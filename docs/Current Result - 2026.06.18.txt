  Reference checkpoint : result_44 / ep_00100  (best-QoS, pre-collapse snapshot)

     recipe — result_47 ck-fix run is validating, fresh full-③ run to follow.)
  Run config           : R_LoS = 0.2 · λ_D = 1.5 · n_var_layers = 3

  Techniques used:
    · Critic warm-up (shared)
    · Oracle warm-up (dual)              — supervised pretrain of the VQC Q-head
        (oracle blocked→IRS routing) AND PhaseMLP (oracle phase). Phase IS
        binding at K=10, so this basin-selection is necessary
        (no-warmup phase stalls ~36%; warm-up reaches ~91%).
    · Power-fairness ③ (full-power)      — blends ALL THREE power axes (split +
        common-dist + private-dist) toward the QoS-optimal allocation. The probe
        probe_oracle_alloc showed the agent's gap (56→96%) is power-allocation,
        not routing/phase. Recommended α ≈ 0.6 (Pareto-aware: higher α buys QoS
        at sum-rate cost and overrides PowerMLP; 0.6 keeps the head useful).
    · Ck-fix (_ck_group_softmax)         — within-group logit-spread clamp,
        structural guard against common-rate head collapse under power shift.
