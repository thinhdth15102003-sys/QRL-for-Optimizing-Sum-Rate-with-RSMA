                      · CkMLP [128,128,64,32]
    Critic          : [512,256,128,64] + PopArt value normalisation

  ── RL / training (shared) ───────────────────────────────────────────────────
    Algorithm       : on-policy PPO (clip) + GAE (λ = 0.9) + entropy bonus
    Rollout         : n_rollout_episodes = 12 per PPO update
    Entropy β       : 0.001 → 0.0003, annealed by 10% of episodes
    Critic          : lr = 3e-4, target_tau = 0.02, cold-start warm-up
                      (16 ep × 50 epochs) before PPO
    Reward          : D_k = 0.10 bps/Hz QoS demand, λ_D = 1.5 (per-ramp knob),
                      reward_noise_avg = 16
    Phase           : 2-bit quantisation (L = 4 levels per IRS)
    Curriculum      : R_LoS ramp 0.2 → 0.5 (blockage hardens as ramp rises)
